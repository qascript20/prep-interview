# Interview Studio

Updated 24 November 2026. The public site is now a single interview workflow beginning on the homepage. It provides a five-question free AI mock and optional £9.99/month Stripe subscription continuation. My track and Progress have been removed from the interface. See [current subscription workflow and verification](SUBSCRIPTIONS.md) and the root README.

Gemini Live still uses the pinned official SDK, a server-only permanent key and one-use constrained ephemeral tokens. Native audio is transcribed for text mode; push-to-talk uses 16 kHz PCM input and 24 kHz PCM output. No microphone is opened without clicking Start speaking. Capture, playback, sockets and timers are released on end/navigation. A typed draft survives a transient connection error. Finish waits for the current reply before requesting a final summary, preventing a previous turn-complete event from being mistaken for final feedback.

The interviewer asks one question at a time, follows up on answers and gives advisory feedback. It cannot execute or grade code, infer ability from voice/accent or predict a hiring outcome. Existing automated AI code-grading gates remain closed.

The permanent provider key is never sent to the browser. Free expiry is enforced through the server token as well as the page timer. Subscribers renew short connections with bounded recent conversation context, rather than receiving an unrestricted long-lived credential. Paid access and cancellation are verified through Stripe before another lease or resource access is granted.

A real synthetic Gemini check completed all five free questions, including a generated voice answer, then returned feedback with no sixth question. A separate earlier paid Live transport check received setup completion, a question and a turn-complete event. Controller tests cover five-question completion, pause/resume, free voice answers, subscription reconnection and final-summary ordering. Free mode uses authenticated question endpoints; paid mode retains the five-minute technical Live leases. Hardware microphone/speaker behaviour and the future hosted identity path still require hands-on verification. No live Stripe payment has been made or claimed.

Questions now play automatically. The previous Spoken questions off and Repeat question controls are replaced by Provide Explanation, Provide Answer and a contextual Stop voice button. Free helpers use server-owned current question context, cache each help type and never increment answers_received; paid helpers use the existing Live session and are separate from candidate answers. AI speech uses server-side Gemini TTS for free sessions, with written text and a labelled local-voice fallback on errors. The live synthetic check generated both help types and speech, with all five questions still remaining.
